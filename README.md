# UXLearn — Mockup Web Lengkap

Prototype mengikuti struktur UTS Media Pembelajaran Informatika: 8 halaman analisis + mockup UI/UX.

Fitur: dashboard, progress, 8 modul materi, video placeholder, Info, Transkrip, checkpoint, latihan kasus, feedback benar/salah, hasil, jalur mengulang, dan Blueprint UTS.

Urutan materi: Dasar UI/UX → User & User Needs → User Flow → Wireframe → Visual Hierarchy → Consistency → Usability → Evaluasi UI/UX.

Catatan: area video adalah placeholder yang siap dihubungkan ke video pembelajaran asli. Isi transkrip di prototype adalah struktur contoh, bukan transkrip video sumber tertentu.
