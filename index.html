Sebuah halaman memiliki tujuh tombol dengan ukuran, warna, dan penekanan visual yang hampir sama. Pengguna kesulitan mengetahui tombol utama. Prinsip apa yang paling tepat diterapkan?

Blueprint UTS

Rancangan lengkap 8 halaman

Checklist internal agar prototype mengikuti seluruh komponen wajib UTS.

⭐ Masalah pembelajaran → karakteristik siswa → tujuan → pemilihan media → struktur materi → aktivitas → navigasi → UI/UX → evaluasi
Halaman 1

Identitas, konsep media, masalah

  • UXLearn; Dasar UI/UX; SMA/SMK.
  • Sulit membedakan UI dan UX.
  • Sulit menerapkan teori pada kasus.
  • Pembelajaran pasif membutuhkan interaktivitas.
Halaman 2

Kebutuhan, media, tujuan

  • Visual, aktivitas, feedback, evaluasi, progress.
  • Web interaktif.
  • Tujuan terukur dan target ≥80%.
Halaman 3

Prinsip desain

  • Alignment
  • Segmentasi
  • Signaling
  • Coherence
  • Multimedia
  • Pengelolaan beban kognitif
Halaman 4

Struktur materi & arsitektur informasi

Dasar UI/UX→User→Flow→Wireframe→Hierarchy→Consistency→Usability→Evaluasi
Halaman 5

Flowchart / User Flow

Masuk→Beranda→Materi→Checkpoint→Latihan→Feedback→Evaluasi→Hasil

Salah → feedback → ulangi konsep. Belum selesai → progress. Mengulang → kembali ke materi.

Halaman 6

Storyboard

  1. Beranda: orientasi + progress.
  2. Materi: video + info + transkrip.
  3. Latihan: kasus + pilihan + feedback.
  4. Hasil: skor + rekomendasi.
Halaman 7

Mockup UI/UX

Beranda, Materi/Aktivitas, Latihan/Evaluasi, dan Hasil.

Halaman 8

Penjelasan UI/UX + analisis akhir

Layout: sidebar + content + card. Tipografi: hierarchy. Warna: ungu untuk aksi/fokus; hijau/merah untuk feedback. Ikon: pendukung. Navigasi: konsisten. Aksesibilitas: kontras, label, keterbacaan, status tidak hanya melalui warna. Usability: posisi, tugas, dan hasil aksi jelas.
